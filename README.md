# Fusemass

Fusemass is a desktop app for Windows (x64 and arm64) and macOS (Apple Silicon).

**Free to download and use.**

## Features

- **Automatic updates** — the app detects new releases and offers to update.

## Download & install

Get the latest build from the [releases page](https://github.com/ammarrik/fuse-app/releases).

**Windows** — run the installer for your architecture:

- `Fusemass-Setup-<version>-x64.exe` — Intel/AMD (64-bit)
- `Fusemass-Setup-<version>-arm64.exe` — ARM (e.g. Snapdragon)

Windows may show a SmartScreen warning since the installer isn't code-signed yet — choose
**More info → Run anyway**.

**macOS (Apple Silicon)** — open `Fusemass-<version>-arm64.dmg` and drag **Fusemass** into
**Applications**.

Because the app isn't notarized yet, macOS may block the first launch — right-click
**Fusemass** in Applications, choose **Open**, then confirm.

## Updating

Already running Fusemass? It checks for newer releases automatically and offers to update —
no manual download needed.
